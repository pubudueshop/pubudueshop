Product Description

The TP5100 charger module is a versatile 2A switching step-down charger designed for 1S (4.2V) and 2S (8.4V) Li-ion batteries with wide DC input support. It provides pre-charge, constant current, and constant voltage charging modes with programmable current settings. Built-in protections include input under-voltage, over-temperature, short-circuit, and battery temperature monitoring, making it ideal for DIY battery packs, solar storage, power banks, and portable electronics.
