Product Description

Toshiba TC9152P Feather-Touch Analog Function Switch IC (DIP-24)

The Toshiba TC9152P is a CMOS feather-touch function switch integrated circuit with built-in high-voltage analog switches, designed specifically for electronic input selection in stereo amplifiers, preamplifiers, and hi-fi audio systems. Sourced with authentic Toshiba Japan markings (TC9152P) in a standard 24-pin Dual In-line Package (DIP-24), this IC provides a reliable, drop-in replacement for repairing vintage and modern audio equipment across Sri Lanka.

Key Features &amp; Highlights

•Wide Dynamic Range Analog Switching: Built-in high-voltage analog switches accommodate wide audio signal swings without clipping or distortion.


•Dual-Supply Audio / Single-Supply Logic Architecture: The digital control logic operates from a single power supply ( $V_{DD} - V_{SS1}$ ), while the analog switch section supports dual-rail ( $\pm$ ) power supplies ( $V_{DD} - V_{SS2}$ ) for clean ground-referenced audio routing.


•Anti-Pop Muting Output: Features a dedicated muting output terminal (Pin 5) that momentarily mutes downstream audio stages during input switching to eliminate audible "POP" noises.


•Direct LED Indicator Drive: Integrated high-current buffer transistors allow direct driving of front-panel status LEDs without requiring external driver transistors.


•Low-Power CMOS Structure: Offers low quiescent current draw and wide supply voltage tolerance.


•Mutual-Reset Input Selection: Supports 5-channel momentary tactile ("feather-touch") switch inputs ( SEL-1 to SEL-5 ) with mutual-reset interlocking, plus an ALL-OFF reset and INH (inhibit) control.

Functional Pin Overview (DIP-24)

•Control &amp; Logic Pins: Includes INH (Pin 2 – Inhibit input), OSC (Pin 3 – Internal clock/oscillator terminal), ALL-OFF (Pin 4 – Deselects all active channels), and MUTE (Pin 5 – Anti-pop muting signal output).


•Selector Inputs &amp; LED Outputs: Supports five independent momentary switch inputs ( SEL-1 at Pin 23 through SEL-5 ) paired with open-collector/buffer LED indicator outputs.


•Analog Signal Terminals: Dual-channel stereo signal inputs and common outputs ( SIG-A and SIG-B switch banks) isolated from control logic rails.


•Power Supply Pins: Separate $V_{DD}$ , $V_{SS1}$ (digital control ground/negative rail), and $V_{SS2}$ (analog switch negative rail) terminals.

*(Note: Always verify exact pin numbers against the official Toshiba TC9152P datasheet or your amplifier's service manual schematic before soldering.)*

Common Applications &amp; Compatible Equipment

The TC9152P is widely used in consumer and hi-fi audio equipment for electronic input source switching (Phono, Tuner, CD, Aux, Tape 1/2):

•Integrated Stereo Amplifiers &amp; Preamplifiers: Found in classic Japanese hi-fi amplifiers such as Denon (e. g., PMA-300V, PMA-900V), Marantz (e. g., PM630), Sony (e. g., TA-V33), and JVC (e. g., AX-70BK).


•Hi-Fi Audio Receivers &amp; Tuners: Electronic source routing between tuner, tape deck, and auxiliary inputs.


•Audio Mixing Consoles &amp; Signal Routers: Low-distortion, pop-free analog signal switching.


•Custom DIY Audio Projects: Feather-touch push-button input selector boards with LED channel indicators.

Repair &amp; Replacement Notes for Technicians

•Part Number Suffix Check: The P suffix in TC9152P denotes the standard 24-pin plastic DIP through-hole package. Do not confuse it with TC9153P / TC9153AP (which are 16-pin electronic volume control ICs) or TC9151P .


•Fault Symptoms: A faulty TC9152P typically causes stuck input channels, failure to switch sources when pressing front-panel buttons, missing LED channel indicators, audio bleed/crosstalk between inputs, or permanent muting.


•Soldering Tip: Because this is a CMOS device in a 24-pin DIP housing, using a quality 24-pin IC socket is recommended during repair work to protect the chip from thermal stress and simplify future servicing.
